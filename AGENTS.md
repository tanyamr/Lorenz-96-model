# Проект: перенос модели Lorenz-96 на PyTorch и нейросетевая поправка

## Цель
Учебный проект, в миниатюре повторяющий настоящую работу с моделями погоды:
1. перенести старую численную модель на PyTorch, сверяясь с оракулами;
2. построить огрублённую модель и обучить нейросеть исправлять её ошибку (гибридная модель).

## Структура
- `reference/l96_numpy.py` — ЭТАЛОН. **Никогда не изменяй этот файл.**
- `oracles/make_oracles.py` — записывает оракулы (вход → выход эталона) в `oracles/oracles.npz`.
- `oracles/oracles.npz` — **не изменяй и не перезаписывай** без явной просьбы пользователя.
- `port/l96_torch.py` — перенос на PyTorch (Задание 1).
- `hybrid/` — огрублённая модель, нейросеть и эксперименты (Задания 2–4).
- `tests/` — тесты. `tests/test_port.py` и `tests/test_reference.py` **не меняй**: это критерий успеха, а не препятствие.
- `results/` — графики и таблицы с метриками.
- `tasks/` — описания заданий.

## Команды
- Установка: `pip install -r requirements.txt`
- Оракулы: `python oracles/make_oracles.py`
- Тесты: `pytest -q`

## Правила работы
1. Перед изменениями коротко опиши план, после — запусти `pytest -q` и покажи результат.
2. Задача решена только тогда, когда тесты зелёные. Нельзя менять тесты, допуски (RTOL/ATOL),
   эталон или оракулы, чтобы тесты прошли.
3. Переноси функции по одной: coupling → rhs_x → rhs_y → rk4_step → integrate. После каждой — тесты.
4. Тензоры: float64; функции должны работать с батчем (`X` формы `(..., K)`, `Y` формы `(..., K*J)`).
5. Все случайные числа — с фиксированным seed. Каждый эксперимент должен воспроизводиться.
6. Результаты экспериментов (метрики, параметры, дату) дописывай в `results/log.md`, включая неудачные.
7. Если что-то неясно или задача противоречит этим правилам — остановись и спроси.
