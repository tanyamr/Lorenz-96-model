# Задание 2. Огрублённая модель

**Идея.** В настоящих моделях погоды сетка слишком крупная, чтобы видеть облака и мелкие вихри.
Их влияние приходится приближённо описывать формулой (это и называется «параметризация»).
Здесь то же самое: огрублённая модель знает только X, а мелкие Y не видит.

Огрублённая модель:
dX_k/dt = -X_{k-1}(X_{k-2} - X_{k+1}) - X_k + F + U(X_k),
где U — поправка вместо настоящего вклада мелких переменных `coupling(Y)`.

## Шаги (давай агенту по одному)
1. Сгенерировать «правду»: длинная траектория полной модели (например, 50 000 шагов с dt=0.001,
   первые 5 000 выбросить как разгон). Сохранить X и настоящий `coupling(Y)` в `hybrid/data.npz`.
2. Реализовать огрублённую модель с U = 0 (вообще без поправки) в `hybrid/coarse.py`.
3. Реализовать простую поправку: полином U(X_k) = a0 + a1·X_k + a2·X_k² + a3·X_k³,
   коэффициенты подобрать методом наименьших квадратов по данным из шага 1.
4. Сравнить три прогноза от одинаковых начальных условий: полная модель, огрублённая без поправки
   и огрублённая с полиномом. Метрика: RMSE по X в зависимости от времени прогноза.
   График сохранить в `results/forecast_rmse.png`.

## Проверь сам
- Модель без поправки должна быть заметно хуже. Если это не так, где-то ошибка.
- Посмотри на точечный график «X_k против coupling». Видно ли, почему полином неплохо подходит?
