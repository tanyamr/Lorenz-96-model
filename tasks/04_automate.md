# Задание 4. Автоматизировать цикл экспериментов

**Идея.** Это главное из доклада: задача формализована (есть метрика — RMSE прогноза),
гипотезы проверяются автоматически, значит, перебор вариантов можно поручить агенту.

## Шаги
1. Попроси агента вынести параметры эксперимента (размер сети, lr, число эпох, длину прогноза
   при обучении «через модель») в конфиг-файл `hybrid/configs/*.yaml`, а запуск сделать одной командой.
2. Режим «вширь»:
   > Предложи 5 разных способов улучшить поправку (архитектура, входы, способ обучения).
   > Проверь каждый быстро, запиши метрики в results/log.md, неудачные тоже. Потом сводка.
3. Режим «вглубь»: выбери лучший вариант и попроси агента выжать из него максимум,
   но с ограничением, например не больше 10 запусков.
4. Прочитай `results/log.md` сам и проверь хотя бы один результат вручную. Агенты иногда
   уверенно пишут неверные цифры.

## Итог
Проект с тестами, логом экспериментов и воспроизводимыми результатами. Такой навык
и нужен для работы с настоящими моделями (WRF, FV3 и т.д.).
