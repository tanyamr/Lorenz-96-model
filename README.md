# Стартовый проект: агент + оракулы + гибридная модель (Lorenz-96)

Учебная миниатюра методов из доклада Д. Сухорукова «Терминальные агенты в задачах
автоматизации доменных исследований»:
- **оракулы**: перенос численной модели на PyTorch с автоматической сверкой с эталоном (как WRF → PyTorch);
- **гибридная модель**: нейросеть исправляет ошибку огрублённой физической модели (как NeuralGCM);
- **автоматизация экспериментов**: агент перебирает гипотезы, метрика проверяется автоматически.

Lorenz-96 — игрушечная «атмосфера» из 8 крупных и 256 мелких переменных.
Она считается за секунды на ноутбуке, но устроена так же, как настоящая задача:
крупная модель не видит мелкие процессы, и их влияние надо как-то описать.

## Установка
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
git init && git add -A && git commit -m "init"
python oracles/make_oracles.py
pytest -q        # test_reference — зелёные, test_port — красные (это задание)
```

## Задания (по порядку)
1. `tasks/01_port.md` — перенос на PyTorch с оракулами
2. `tasks/02_coarse_model.md` — огрублённая модель и полиномиальная поправка
3. `tasks/03_nn_correction.md` — нейросетевая поправка
4. `tasks/04_automate.md` — автоматический перебор экспериментов («вширь» и «вглубь»)

## Как работать с агентом
- Запусти агента в папке проекта (например, `claude`). Он сам прочитает `CLAUDE.md` с правилами.
- Делай `git commit` перед каждым заданием. Если агент всё сломал: `git restore .`
- Смотри `git diff`, а не только сообщение агента.
- Если агент «чинит» тесты вместо кода — останавливай. Это запрещено в `CLAUDE.md`.
